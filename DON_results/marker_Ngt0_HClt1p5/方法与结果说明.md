# DON 来源端元特异候选 marker

本版承接最新的 N>0、H/C<1.5 筛后逐样本网络，以 RI≤1 为主规则，并保留 RI=0 的严格标记。

## 来源与受体

根据用户PPT“湖泊和marker”的溯源结构，Lake作为受体，不参加来源特异性排重。9类来源为Algae（藻类）、Apatit（磷矿，沿用原目录拼写）、Aquaculture（水产养殖尾水）、Excrement（畜禽粪便）、Fertilizer（肥料）、Plant（植物）、STP（污水处理厂尾水）、Sediment（底泥）、Soil（土壤）。共50个来源样本、10个Lake样本。

这一来源/受体定义决定marker含义；若以后把Lake或其他类别改作来源，必须重新排重。

## 筛选顺序与标准

1. 使用已经完成的逐样本筛后网络：实测m/z 200–900 Da、正强度、有效元素组成、排除原表明确同位素峰，再筛N>0、H/C<1.5，最后在各样本筛后集合内计算候选转化次数。
2. 某来源中至少有一个检出分子峰的转化次数≤1，则该分子式进入该来源的RI候选。主名单没有再加未经指定的检出率阈值。
3. 按完整C/H/N/O/P/S分子式对齐，要求它在其他8类来源的全部有效检出分子中均未出现。排重背景来自前版完整188,411条有效峰记录，包含非RI峰。仅在另一来源“不属于RI”不能据此判断为独有。
4. Lake不用于删除来源候选；另外记录每个候选在10个Lake样本中的检出情况和原始强度。Lake检出不要求它在Lake中也属于RI。
5. 强度是原始峰强，不是浓度。分子式对应多个峰时，在强度矩阵中求和；用于后续建模前还需按实验设计确定归一化。来源检出率分母是该类全部来源样本数，不只RI样本数。

## 结果

4,204个“来源×RI候选分子式”组合，排除其他来源也检出的3,478个，得到726种来源独有RI候选分子式。726种分子式互不重复，各只归属一个来源。

| 来源 | 独有RI候选 | Lake检出 |
| --- | ---: | ---: |
| 藻类 Algae | 22 | 12 |
| 磷矿 Apatit | 27 | 8 |
| 水产养殖尾水 Aquaculture | 83 | 28 |
| 畜禽粪便 Excrement | 75 | 21 |
| 肥料 Fertilizer | 61 | 2 |
| 植物 Plant | 60 | 10 |
| 污水处理厂尾水 STP | 39 | 20 |

| 合计 | 726 | 173 |

- 173种在Lake检出，553种在当前Lake样本未检出。未检出不等于不存在或无贡献。
- 484种在对应来源至少有一个峰为严格RI=0。
- 672种在对应来源全部检出记录中的次数均≤1；其余54种仅部分来源样本/峰符合RI。
- 75种在对应来源至少两个样本检出，其余651种仅在单个来源样本检出。保留这些标记供后续稳健性筛选，不将单样检出的特异性当作充分验证。

这里的“marker”是当前样本、来源类别、数据库和条件下的候选标志分子。未进行统计验证、随机森林/XGBoost/SHAP或贝叶斯贡献估计，不能把173种Lake检出直接解释为来源贡献比例。当前全部候选用于筛查；后续应结合重复性和实验设计验证。

## 主要字段

- source：来源端元；formula：完整分子式；marker_id：本次名单追溯编号。
- source_detected_samples / source_detected_fraction：对应来源全部样本中检出该式的样本数/比例。
- source_RI_le1_samples：检出该式RI≤1峰的来源样本数；可小于source_detected_samples。
- RI_le1_all_source_observations：是否在所有检出的来源记录中都符合RI≤1。
- RI_eq0_any_source_observation：是否在至少一条来源记录中为0次；不是所有记录都为0。
- RI_eq0_all_source_observations：是否所有检出的来源记录都为0次。
- source_at_least_2_samples：是否在至少两个来源样本中检出，未将此条件强制用于主名单。
- lake_detected_samples / lake_detected_fraction：在10个Lake样本中的检出数/比例。
- other_source_detected_count：主名单均为0；原始排除信息见审计表。
